# Analyse csv

# Auteur
Barnabé Landry Evouna

# Description
Programme Java qui analyse un fichier CSV.
- Lit le fichier CSV
- Calcule la moyenne, minimum, maximum par colonne
- Affiche les résultats dans la console
- Génère un rapport CSV

# Fichiers
- Main.java : point d'entrée du programme
- MonAnalyse.java : classe d'analyse des données
- Projet3.java : lecture et sauvegarde du fichier CSV Day

# Instructions
1. Ouvrir le projet dans IntelliJ
2. Modifier le chemin du fichier CSV dans Main.java
3. Run Main.java
